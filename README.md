# KyliesInventoryApp
Inventory Android App

CS 360 Portfolio Reflection – Mobile App Project

App Overview and Goals

This project is an inventory management Android app designed to help users keep track of items, quantities, and basic product information. The goal of the app is to provide a simple and organized way to manage inventory without needing complex systems. It was built to solve the problem of manually tracking items or losing track of stock.

User Needs and Design Approach

The app was designed with ease of use as the main priority. Users need a quick way to view, add, and update inventory items without confusion. The interface keeps things simple with clear labels, minimal screens, and straightforward navigation. The design avoids clutter so users can focus on managing their inventory efficiently.

Screens and Features

The app includes a main inventory screen where users can view a list of items. From there, users can add new items, update existing ones, and manage quantities. Input fields are clearly labeled, and buttons are placed in familiar positions to make actions feel natural. Each screen has a clear purpose, which helps users complete tasks quickly.

Development Process

I approached development by building the app step-by-step, focusing on one feature at a time. I kept my code organized and readable so it would be easier to debug and maintain. Breaking the project into smaller parts made it more manageable and helped reduce errors. This is a strategy I will continue to use in future projects.

Testing and Functionality

Testing was done throughout development by running the app and checking each feature as it was completed. This helped identify issues early and ensured that all functions worked correctly. Testing is important because it improves reliability and creates a better user experience. It also helped me catch small bugs before finalizing the app.

Challenges and Problem Solving

One challenge was making sure the app stayed simple while still functioning correctly. It took some trial and error to balance usability with functionality. I had to adjust parts of the design and code to make everything work smoothly together.

Strengths and Key Accomplishments

One of the strongest parts of this project was turning a basic UI design into a fully functional app. I successfully connected the front-end design with the app logic, creating a working inventory system. This project shows my ability to design, build, and test a mobile application from start to finish.
